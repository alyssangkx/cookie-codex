# Terminology: sub-topic in code, section/topic on screen; "Exam-ready" for the competency badge

Status: accepted · Date: 2026-11-20 · Source: owner, chat 20 Nov 2026

**Context.** The glossary found two clashes: "category" vs "sub-topic" vs "section", and "Competent" used both as a tier
name and as the planned competency badge.

**Decision.**
- Code and docs say **sub-topic**. On screen, each subject uses the paper's own word: **section** for English and
  Chinese, **topic** for Math and Science.
- The assessment cycle's top competency state and its badge are called **Exam-ready**. "Competent" stays only the name
  of the third tier.

**Consequences.** New pages and copy follow this wording. The learning-loop design and the to-do list are updated. The
English school page already says "sections".
