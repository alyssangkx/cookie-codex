# Submit-then-review applies to WA/SA papers only; tier quizzes keep instant feedback

Status: accepted (design 20 Nov 2026; papers flow going live 20 Nov 2026). Source: `docs/learning-loop-design.md` section 2, `docs/todo.md` (Schedule).

**Context.** An exam is answered without feedback, so a paper that marks each question as you go trains the wrong habit. Tier quizzes and Daily Review exist to teach, where immediate feedback helps.

**Decision.** WA/SA papers show no right or wrong until Submit, then review only wrong and blank answers. Tier quizzes and Daily Review keep instant feedback. Mastery and card rules do not change; papers never retire questions.

**Consequences.** Papers need a draft (resume after reload or a locked phone), a timer with one pause, and a review mode. Wrong or blank answers still become due in 1, 3 and 7 days; correct new ones do not drain tier pools.
